## 引用前的规矩

- **EXP-008弱损失解释更正（2026-11-04）**：默认L1比较正负包的峰谷差，不是两包最高分之差；平滑与稀疏项只用正包。旧报告与数字保留，引用解释请同时读[损失函数澄清](EXP-008-损失函数澄清.md)。机制风险不等于历史失败主因已查明，也不代表所有弱监督方案已被否定。
- **分类头名词更正（2026-11-03）**：旧冻结strong线的`StrongHead`实际为512→128→64→32→1的MLP，含ReLU／Dropout，部分旧材料称“线性头”不准确。不能将其与EXP-020的`Linear(512,1)`混称；有上下文的旧头输入为576／640维。代码正本为`experiments/common/video/train_strong.py`，旧报告与数字不追改。
- **时间尺度解释更正（2026-11-03）**：EXP-009／014旧说明中“预训练16帧跨约10秒”“7.5秒匹配预训练尺度”“短输入使滤波器几乎不响应”的推理证据不足。官方权重文档给出的是16帧、15fps、每视频5窗的评价设置，不能据此反推训练跨度。见[预训练时间尺度与采样跨度澄清](../../data/预训练时间尺度与采样跨度澄清.md)；本项不改历史指标，也不确定3秒或7.5秒优劣。
- **EXP-008 的数字可引用**，但引用时要带 run-log 第 24 条写明的两条条件；
- **EXP-009 的产物已过事后审查，但 0.9909 不是独立测试成绩**：每折在被考核视频上选择最好轮次；历史执行脚本未留冻结副本，当前脚本不能证明字节级复现。与冻结线的配对差已用保存权重和完整精度分数更正为+0.047809、95%区间[+0.00625,+0.102729]；该区间未涵盖训练种子、选轮和同场次相关性；
- **EXP-014 的主判据可作描述性证据，但两套 0.9923 都不是独立测试成绩**：可写“新间隔模型的片段分数对倒序更敏感”，不可据此说识别能力提高；约四成净差来自只有 2 条负样本的第 4 折，负样本整体方向相反；新间隔有 7 条漏报（原间隔 0 条），其中 1 号塔下游 5 条正样本整组漏报；两边的可用片段和强标签数量不同，比较的是整个采样方案；绝对成绩不能与 EXP-009 直接比。依据见 `EXP-014-训练报告.md`；
