# 模型具体怎样使用

2026-11-08。将已经运行过的能力和下一版设计分开说明。

## 输入一条视频，用户会得到什么

用户上传一条固定摄像机视频，不需要先标正负区间。系统读取真实时间戳，在过去约3秒取16个不同的帧，作为一次模型输入。帧率不同也按秒定位，不把“连续16帧”当成固定3秒。

第一份输入收齐后输出一次结果，再向前移动一段时间取下一份。EXP-028首轮规格先固定步长3秒，控制训练和评价成本；0.5秒是以后更密时间线的候选，尚未实施。旧EXP-022实际密集评价约1.5秒一次，不能混称同一个评价网格。

工作台展示三样内容：

1. **分数时间线**：何时出现目标证据，分数怎样变化。
2. **可回看的候选告警区间**：点击后跳到对应原视频；不只给整条视频一个正/负结论。
3. **输入说明**：这次判断看了哪段约3秒，分数到何时才可获得；技术损坏或支持不足时显示缺口，不伪装成负类。

它识别画面中已经出现的目标，不预测未来。开始不足一份完整支持时不能硬复制帧凑输入。长视频可以持续滚动处理，训练时的48片段配额不是部署时长限制。

## 如果下一版保留N/T/P，三分数表示什么

N表示明确非目标，可包含普通水流/洪水。P是当前已清楚可辨的目标，小型或阵流性也可以是P；T须同时有当前目标存在的肯定依据和具体受限的辨认线索，不按大小分灾害等级。类型仍未定则记U。当前可靠T只有一个机位，首轮先准备存在二类B0，不启动三分类V0。

对一份约3秒输入，模型输出N/T/P三个和为1的分数，拟合该窗各状态的时间组成。例如3秒里2.8秒N、0.2秒T，训练目标为(0.933,0.067,0)，不把整窗硬标T。真实预测会有误差，这些比例不是保证测准的时长。

三类候选的主要检出分数使用T+P，可靠T同样属于“已存在目标”；P单独分数表示该窗内清楚可辨状态的组成。当前B0直接学习同一存在目标。T不预设为0.5，也不表示未来将发生大事件。

所以用户看到的是“这一段输入里有多少目标证据、是否达到验证选定的告警规则”，而不是流量、危险等级或地学认证。窗口含过去N时可能推迟越阈，退出后也可能残留分数；评价要实测误报、漏检和响应等待。

是否保留三分类，由真实跨机位标签一致性和二类/三类共同对照决定；如果T/P不能稳定定义，则采用更清楚的存在二类时间线，而不强凑第三类。

## 分数和告警怎样分别评价

输入窗的组成误差比较分数与这段过去输入的真实时间组成。应用告警则从分数实际可用时刻开始，保持到下一次输出，与这段持有时间的当前真值相交计分；两种时间域不能混用。

主存在时间Recall的分母包含全部技术有效且mask_existence=true的明确T/P时长；候选P不作真值。开始及技术断裂后的积累期没有告警，仍算未检出，并单列无输出时长；另报有输出域的Recall。U与候选只屏蔽真值计分，不重置取样和预测，技术断裂才重置。误报同时报告N域误报时长比例、N域连续误报段数/已知N小时，跨未知或QC不拼接。若仅用视频PTS视为分数可用时刻，则报告视频时间等待，实际推理耗时另测。
