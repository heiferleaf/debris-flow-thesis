# 预训练时间尺度与采样跨度澄清

2026年11月3日更正：不能把Kinetics来源视频约10秒的片长，直接当作R(2+1)D-18预训练权重每个16帧输入窗的跨度。Torchvision对`R2Plus1D_18_Weights.KINETICS400_V1`所报成绩明确给出的是**评价设置**：`frame_rate=15`、`clip_len=16`、`clips_per_video=5`。在均匀15fps的16个采样时刻下，单窗首尾相隔约1秒；这条说明不等于该权重训练采样的完整配方，也不能反向断言训练窗必定为1秒。[官方权重文档](https://docs.pytorch.org/vision/main/models/generated/torchvision.models.video.r2plus1d_18.html)

## 三个量要分别说明

来源视频总片长是可供取样的素材长度。单窗首尾跨度是一次输入中末帧与首帧时间戳之差。每视频评价窗数是为了得到视频级成绩取了多少个窗口，不能将5窗合并叙述为一个连续的长窗。

均匀采样时，首尾跨度为

\[
\Delta t=\frac{T-1}{f}=\frac{16-1}{15}=1\ \text{秒}.
\]

其中，\(T\)是采样帧数，\(f\)是采样频率（每秒帧数），\(\Delta t\)是首末采样时刻之差。若另按16帧的显示支持计算`16/15`秒，那是另一种时长口径，仍不是约10秒。实际文件中的取样跨度应按所选真实PTS计算。

训练与评价也须区分。上述官方文字限定为视频级准确率的评价参数；本次没有据此补全或假定该权重实际训练时的全部采样、随机裁窗与时间增强配置。要声称“匹配预训练采样”，需要与具体权重及版本对应的训练配方证据，不能只引来源视频片长或评价元数据。

## 对既有论据的更正

- `docs/process/experiments/EXP-009-训练报告.md`第255行把“约10秒均匀抽16帧”当作已确认的预训练方式，并据此断言本项目运动幅度小一个数量级、时序滤波器几乎不响应。此链条缺少对应训练配方及滤波器响应证据，不应继续作为确定原因引用；第260行以3–10秒“匹配预训练尺度”的建议也不能沿用该论据。
- `docs/process/experiments/EXP-014-训练报告.md`第21行将7.5秒输入称为接近预训练十秒级片段。来源视频片长不足以支持这种匹配关系；7.5秒只是该实验实际采用的采样方案，不能因此声称优于短窗。

适用的表述应是：**采样跨度可能改变输入中可见的运动与内容，但是否造成时序响应偏弱仍是未验证假设。**逆序或重复帧扰动下的低敏感性，也不能独自证明滤波器不响应或将根因定为片段过短。本次事实更正不证明7.5秒更好、3秒最优，也不改变旧实验的输入、设置或已保存指标。
