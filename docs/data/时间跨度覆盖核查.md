# 3秒与7.5秒输入的元数据覆盖

2026年11月1日按现行metadata-v4的标注、连续质量净区及真实PTS进行独立核查。按视频自身标签，3秒16帧可覆盖150/150条；7.5秒及同名义中心配对可覆盖140/150条。该结果是数据可行性证据，不是模型效果或像素验收。

## 口径与结果

两种跨度均使用16个不同、递增的真实帧，逐目标点误差不超过0.100001秒，整窗处于同一原标签sampling区间与一个质量净区。长窗以真实PTS为目标起点`s`，短窗目标起点为`s+2.25`，共同名义中心相同；实际中心最大差为0.10005秒，不能写成实际中心完全一致。

- 全部150条为113条正视频、37条负视频。3秒覆盖113P／37N；7.5秒及共同中心配对覆盖105P／35N。
- 冻结开发划分中，训练侧长窗覆盖109/119条，验证侧31/31条。缺少长窗的10条全部属于训练侧，当前EXP-019仍使用其合法3秒输入，没有删去。
- 原先因不足48窗排除的22条中，当前12条（10P／2N）有合法7.5秒窗；剩余10条（8P／2N）在自身标签下没有合法长窗。取消48窗要求解决了其中12条的问题，不能据此说全部22条都能使用7.5秒。
- 零长窗名单为`v1_111、v1_112、v1_114、v1_45、v1_47、v1_48、v1_49、v1_73、v1_76、v1_77`，位于鸡冠山上游的2025-07-19、07-24、07-29三个场次组；各自最长同标签连续净区的实际首末PTS跨度为3.65—6.10秒。此处描述冻结可用区，不表示原视频文件总时长只有这些。

原3秒全候选3,028,407个，逐段与原NPZ、数量和摘要完全一致；7.5秒去重长元组3,007,562个，同名义中心的短长元组对3,004,483个。后二者计数域不同，差值不能直接解释为缺少配对的长窗数；这些候选大多重叠，也不是实际训练曝光量或独立样本数。

## 能支持的决定

当前3秒参照可保留全部150条，不代表已经选出最佳跨度。后续比较7.5秒时，应明确比较总体及共同合法窗口；若只改变一组的数据构成，差异就不能单独归因于跨度。没有长窗的视频继续保留，不缩窗冒充7.5秒、不复制帧、不拼接禁区或延长标签。任何共同子集或可变跨度训练方案仍需另行成卡、审查与输入验收。

本轮只核元数据，没有打开或哈希视频／锚图、没有取帧、没有读取模型分数或外部候选。媒体身份继承冻结记录；不是再次证明像素无损。186个监督段、300个video×class行、62个group×class行完整记账，并区分人工标注与协议9隐式监督段，以及无监督段、零合法窗和零配对。
