## 三个标签表达什么

- **N：当前可归为项目负类状态。** 包括静止沟床、普通流水、含沙水流或洪水，以及已认可的细流；不要求画面静止。
- **P：当前连续画面足以明确辨认目标泥石流输运。** 小型、缓慢、细颗粒或阵流过程都可能是P，不要求占满画面、不机械要求可见大石块，也不要求所有典型特征同时出现。
- **T：当前已有具体来料进入、显现或发展迹象；完整过程支持其与后续目标连续关联，但局部画面尚不足明确辨认为P。** 它是离线过程阶段，可以依赖前后视频内容，不是全局相同规模的中等流态或“拿不准”的类别。不同视频的T外观可以与其他视频的N/P相似，不能强迫孤立片段单独可分。远、小、流量增大或未来出现P任何单项都不充分；当前已经清楚的目标仍直接P。

T不能成为所有难例的收容类别。如果只有“有流动、很黄、变宽、规模小、我拿不准”，没有具体目标征象，就不足以新增T。无法充分推翻旧标时，可以保留旧工作标签并单列把握和缺证；不能把这种继承写成再次独立证实。当前不新增U/A，用户已有cut保留，画质和缺图另记。

## 怎样看画面

1. **先定位实际流体，再沿时间看。** 固定岸石、沉积岛和沟壁只作位置参照；它们不动不能推出流体不动。看前缘和内部组织是否相对固定地物持续推进、替换，以及是否形成可辨的物料体输运。
2. **用同一套人工对照样例校准。** 对照样例是用户认可的视觉状态，不是地学认证。普通水流也会浑浊、翻涌和阵流；颜色、流宽、速度、阵流波动、来源目录任何单项都不能独立定类。
3. **对T写出差异和缺口。** 例如原细流之外出现持续推进的新灰浊粗糙前缘，但当前组织尚不足稳定辨认。不能仅因远、小或雾遮就T；已经清楚可辨的小目标仍可P。
4. **阵流按实际延续判断。** 阵头、阵体及阵间若仍明确是目标，都可P。不能每个波谷必N或必T；也不能把只有前缘才P当全局规则。
5. **跨文件保持语义一致。** 相邻文件若画面时钟近连续、流态接续，不能只因换文件就改类；仍须看本片的实际流体证据，不能用上一片候选标签循环证明下一片。
6. **分开观察与推断。** 保存实际查看时段、位置、图证、来源及把握；抽样之间的时域不得冒称连续认证。缓存用于定位，关键变化补有限原片窄窗。审计秒、原片PTS、seek请求和画面OSD分列，未经配准不得互换。

来源方的事件说明是重要补证，但不是每秒标签。v4较晚原文确实更正前批塔吊断面为小型泥石流，不能据早期“事件前水流”说明批量改N，也不能据更正把所有下游、所有时间都认证为P。过时的“整段负样本”快捷操作备注不覆盖显式区间。
