# v4、v5标注区间的抽样复核

更新：2026-11-05。

本次按审计台当前保存的全部50个区间选图：44条视频、16个正区间、31个负区间、3个cut区间。每段取近起点、四分之一、中间、四分之三和近终点各一帧，共250帧；不使用模型分数选样。长区间五点抽查不能证明每一秒均正确，但足以核查是否存在明显的类别反置或大段状态差异。

**此次抽样未发现要求改动现有P/N/cut的明显画面证据，建议保留标注。** 用户当日重新查看后也认为审计没有问题。旧“预填、待审计”备注属于确认记录不完整，不能据此认定标注未审核或错误。本次没有修改events、冻结训练输入或历史成绩。

范围更正（2026-11-06）：本报告只覆盖44条v4/v5，全150条的代码、元数据和输入质量核验不等于人工标签语义核验。剩余106条v1随后已补齐抽样，发现与范围见[主诊断第7节](../process/experiments/EXP-022-错误诊断与既有改进复核.md)；本报告本身不能排除其他视频的内容或标注问题。

## 只保留少量动态待查

- v4_18约1746–1786秒：若需要解释正区间精确起点，可看cut与P之间的连续变化。
- v4_10、v4_11末尾约20秒：若论文需要声称“正在流动”，需区分宽幅覆盖、活动通道、灯光与阴影；不据静态覆盖断言运动停止或持续。
- v5_09后半段、v5_10或18的一小段：仅在分析两类运动差异时，作为“有明显浑水/流动仍为N”的代表，不要求重新标注全部负视频。

这些是观察范围的限制，不是已经发现的错标签。现有证据不支持全库重标或整体退回弱监督。

三处cut可作为训练中的过渡忽略段保留，不能全部解释为灰帧或剪辑。现有准备代码把人工cut与QC共同排除于dense可用域，这属于评价范围限制；后续部署和外测要把训练忽略与技术质量剔除分开，不预先借助正负状态边界筛选视频。

## 与训练诊断的关系

标签有可辨认的视觉依据，不等于112×112模型输入保留了全部依据，也不等于训练覆盖了不同日期、光照和流态。正负都有运动，额外提供帧差或通用变化能量并不必然改善分类。后续应分别检查输入信息损失和跨场次迁移，而不是把模型错误反过来当作标签错误。

现有审计JPEG也不都等于原视频原始分辨率：v5的D02审计图为1920×525，对应原视频5120×1400；其他v5主要为1920×1080。抽样索引保留实际JPEG尺寸；视频原始尺寸以对应媒体和转码日志为准。
