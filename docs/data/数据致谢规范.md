# 数据来源标注与致谢规范

- **适用**:所有使用东川泥石流观测研究站数据的工作——毕业论文及其衍生(期刊/会议投稿、专利申请、专著出版)。
- **来源**:东川站数据使用要求(叶海峰 2026-09-14 转录,随申请数据时对方告知)。
- **效力**:写论文涉及致谢/数据来源时**必须**按本规范执行;`cs-capstone-thesis` skill 已挂指针。

## 1. 数据来源标注

在论文发表、专利申请、专著出版等工作中**标注数据来源**:
- 数据:云南东川蒋家沟泥石流视频(NCDC 平台,DOI: 10.12072/ncdc.ddfors.db7468.2026 与 10.12072/ncdc.ddfors.db6807.2025);平时时段录像(申请获得后按站方指定方式标注)。
- 引用格式:按 NCDC 元数据页给出的格式(宋东日、钟卫、黎晓宇、魏丽,2026)。

## 2. 致谢文字(逐字使用)

**中文出版物**,致谢部分必须包含:

> 感谢中国科学院东川泥石流观测研究站为本研究提供了相关数据

**英文论文**,致谢部分必须包含:

> We would like to thank the Dongchuan Debris Flow Observation and Research Station (DDFORS), Chinese Academy of Sciences, which provided the field observation data for this study.
