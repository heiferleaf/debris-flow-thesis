# 工作区组织规范

本文件承接AGENTS.md的目录细则；目录维护不改变研究事实、标签、训练协议或授权。

## 文件职责

| 位置 | 应放内容 |
| --- | --- |
| `docs/` | 按科研过程组织的论文参考资料：背景、可行性、数据方法、实验报告与文献；不放助手排错流水 |
| `data/raw/` | 当前原始媒体及明确登记的处理后原片入口；保留来源、处理与指纹，不在多个位置复制大文件 |
| `data/metadata/` | 来源、人工标注、版本指针、冻结划分与复现清单；历史版本有身份和来源，当前版本有唯一指针 |
| `data/process/` | 可追溯中间件和缓存；区分实际训练输入、必要证据和可重建临时件 |
| `data/final/` | 已明确用途的最终数据，不因目录名推断已验收 |
| `data/results/<实验线>/<run_id>/` | 权重、特征、原始预测、指标、环境和运行日志；保留run_id，不覆盖旧结果 |
| `experiments/common/` | 跨实验复用的实现，不放只属于一张实验卡的流程 |
| `experiments/tools/` | 与实验编号无关、参数化且可复用的通用命令行工具 |
| `experiments/runspecs/EXP-NNN/` | 每实验独立入口、配置、专用分析/报告/收集脚本，调用common；不复制训练循环 |
| `experiments/splits/code/` | 划分与隔离检查代码；冻结成员在data/metadata/splits |
| `experiments/tools/oneoff/` | 确有复现价值的已结束一次性脚本；其余一次性件用后删除 |
| `paper/` | 论文正文、学校模板与提交材料 |
| `.codex/docs/` | 内部计划和工作说明；唯一当前入口为当前研究状态.md，结束说明只留必要摘要和证据入口 |
| `.codex/logs/` | 一份研究证据记录、简短过程摘要和必要机器证据；不累积重复的助手叙述 |
| `.codex/docs/.temp/` | 临时构建、核对帧和试验件；完成用途即清理，不作为长期运行依赖 |
| `.codex/logs/playwright/` | 浏览器临时截图、快照与控制台输出；论文图另放正式材料目录 |
| `.agents/skills/`、`.codex/agents/` | 唯一技能正本、角色配置；不维护Cursor/DSH/Claude副本或旧链接 |
| `.codex/secrets/` | 本地密钥，仅忽略、不输出、不提交 |

根目录只留项目说明、AGENTS.md、版本管理与运行环境配置；改变顶层结构先说明理由。文件名用实际`AGENTS.md`，不另建AGENT.md/Agnet.md等副本。

## 入口和历史

- `.codex/README.md`只导航；`.codex/docs/当前研究状态.md`是唯一当前工作叙述。已结束计划的有效决定归入研究记录、过程摘要或正式实验卡，不重复保留旧状态全文。
- 不维护并行任务JSON等第二套研究结论；辅助快照完成用途即清理。
- 实验说明从`docs/process/experiments/README.md`查，代码入口从对应runspec查，当前数据从`data/数据清单.md`查。
- 迁移先更新当前引用与运行依赖；冻结run、原指标和原代码快照保持原字节，旧路径通过迁移映射解释。

## 清理和版本管理

- 清理前确认不在运行引用，不触及原始采集、用户标注、现役输入、选定实验的有效权重及唯一必要证据。可重建帧/缩略图/试验包用后删除，记录范围和真实删除结果。
- 按用途结束实验文件生命周期：设计或实现错误导致的作废版本，只留原因、原run身份和必要证据；其权重、专属中间数据、临时工具及时删除。已结束冒烟/计时只保留能影响复现的小记录，不长期保存测试权重。无提升但执行有效的负结果不据此作废，代码是否保留按用户选择。
- 清理按具体版本和依赖进行，不按实验编号整目录推断。共用函数、现役读取的元数据先保留或迁回公共位置；解除旧依赖后再删废弃实现、测试和缓存。删除留一份范围/原因/结果回执，不另复制整套文件当归档。
- 编号对应独立研究问题及实验结果。冒烟、测速、离线诊断、数据准备和同一方案修订附属于该实验；未执行草案在计划中管理，不因更新一次方案就占新编号。旧编号统一整理前保留映射，不追改历史run_id。
- 硬链接不是独立副本；清理时只解除目录项，不跟随junction、符号链接去递归删除目标。空间统计区分逻辑大小与实际释放。
- 下载件归档且确认完整后删下载副本；唯一来源和待人工确认素材保留。第三方源码/已使用权重有正式归属，不留在临时目录。
- 代码、规则、必要说明和冻结小清单进Git；大媒体、权重、缓存、密钥和可再生大表不进Git。
- Git按改动目的分组；不把同时进行的研究变更混入维护提交。不重写历史或强推，不手删.git/objects；正常GC保留可达对象和恢复保护。
- 实验公有归档用独立Git历史、总索引及逐实验分支进行逻辑组织，不在本地长期保留复制的实验目录或多版导出包；详见[实验Git归档规范](experiment-git-archive.md)。只发布最终有效结果和数据元信息，不推送现役开发树的完整旧历史。
