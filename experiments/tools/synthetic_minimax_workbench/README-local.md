# 通用水流处理工作台

把一张已有水面的图片制作成12秒水流动画。图片和处理结果保留在本机，不需要视频生成账号或API密钥。当前版本用于科研试片和视觉探索，尚未完成所有场景的质量验证。

## 可以做什么

上传首帧，圈出可流动水面，沿上游到下游画流向，再圈出需要保持静止的石头、桥墩等。工作台支持拖动顶点、撤销、保存标记、抽样预览、完整生成、停止任务，以及下载视频和运行记录。刷新页面后可恢复保存的标记和任务记录。

首帧必须已经包含希望呈现的水面纹理。本工具不会自动把干河床变成水流，也不会自动辨认所有石块。图片最长边超过2048像素时会缩小，原始与处理尺寸会显示在页面中。

## 在Windows上安装

需要64位Python 3.10或3.11。建议16 GB内存和至少3 GB可用磁盘空间；目前使用CPU，无需独立显卡。以下命令在解压目录的PowerShell执行：

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install --upgrade pip
./.venv/Scripts/python.exe -m pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cpu
./.venv/Scripts/python.exe -m pip install -r experiments/tools/synthetic_minimax_workbench/requirements-local.txt
./.venv/Scripts/python.exe experiments/tools/prepare_local_water.py
```

首次准备需要下载作者公开的模型权重，约230 MB。准备程序验证文件哈希；已安装的文件不会重复下载。本机已验证Python 3.8、PyTorch 2.4.1 CPU的推理流程；上述新安装环境仍需接收方实际安装验证。

如果自动下载失败，可从[作者提供的模型链接](https://drive.google.com/file/d/1sNY4_58EMQKNiunBYsJiZ3jcPWAqGYBA/view)下载，改名为`baseline2-motion2-fixedMotionFinetune.pth`，放入`data/results/synthetic-video/pretrained/slr-sfs-fa8d610/`，然后重新执行准备命令。

## 启动与使用

双击分享包里的`start-local.cmd`，或执行：

```powershell
./.venv/Scripts/python.exe experiments/tools/synthetic_minimax_workbench.py --local-only --open-browser
```

工作台地址为`http://127.0.0.1:8774/local`。如果端口被其他程序占用，可在启动命令后加`--port 8777`。处理期间保持服务终端打开，浏览器可以刷新。

1. 上传清楚的有水首帧，优先使用原图。
2. 沿水面边界圈出可流动区域，避免把岸边包含进去。
3. 沿水面从上游到下游依次点击，路线不要穿过石块。
4. 使用“保护石头 / 固定物体”圈出每个固定物体，点击完成后继续添加下一处。
5. 先看5个时刻，检查范围、石头和边缘；再生成完整12秒视频，检查运动是否自然。

输出每秒12帧。处理时间与图片尺寸、水面范围和电脑性能有关，完整视频可能需要数分钟以上。一次只运行一个任务。抽样预览仅生成5张检查图，不把它冒充为完整12秒视频。

## 目前的质量边界

当前实现使用人为指定的二维流场驱动预训练模型的特征，再把水面合成回原图。它没有求解浅水方程，不是该河道的水文复现，也不是论文方法的完整复现。

项目场景页另有正在验收的计算流场试片，尚未接入本通用包。不能把通用页的输出等同于场景页的新试片，也不能将某一河道的假设水深、坡度和相机尺度直接套用到任意上传图片。

原图纹理增强试验出现过石头随水移动、边缘像贴图平移的问题，因此通用页默认关闭这项增强。固定物体保护区能保持其中的原图像素；它不会自动计算水如何绕过石头。仍需检查遮罩边缘、波纹形态和运动自然程度。背景和保护区在编码前保持原图像素，MP4压缩可能造成轻微像素变化。

这些结果不自动视为训练负样本，也不代表已经证明训练收益。是否适合作为某项任务的数据，应另行判断。
