# 外部视频存在性拟标签：2026-11-01

本包将当前22个媒体逐项整理为 **8 pos、11 neg、3 uncertain** 的拟标签，不改catalog、raw或正式测试状态，不读取模型分数。审查人为“Sol视觉与来源复核（非用户签字）”。这些是可复核的标注建议，不是用户签字或正式冻结；正式测试仍为0。

`video-label-review.csv`保留每条的媒体身份SHA、具体可见依据、来源URL及归档定位、实际看过的图和帧号/PTS、未看范围、保守区间、组关系、风险和下一步。`review-source.json`绑定11份来源元数据、21张实际查看的联系图及CSV的SHA。媒体SHA继承已验清单与原完整解码/迁移证据，本轮没有重读、重哈希或重解码原MP4，没有读取训练结果。

## 已作出的判定

Sheaf拟为neg：34个已显示时点覆盖0至180.013167秒，能看到浅水、裸露/水下河床石块、稳定岸线与普通水面，没有看到不透明颗粒性体流前缘或沟道被碎屑充填。EIDC的河面测速来源是佐证，不能单独充当无泥石流证明。

USU逐条实际看过12时点联系图。普通浅水、可见河床与稳定岸线的9条、以及仍能看到中央河流但受强逆光影响的1条，给出有范围限制的拟neg；强逆光一条另列困难层，不进最小建议子集。First dam May14与UWRL May13两条不透明湍急浑水保留uncertain：现有稀疏图无法可靠区分高流量河水与泥石流。UWRL Night April1因黑暗及下部大片近镜头亮斑遮挡，也保留uncertain；不以“没看见”强行判负。低光、雪景与镜头水滴分别保留困难标记。

HPCC、Chalk Cliffs两年、Elk及Silverado结合官方事件来源与可见灰色浓稠/颗粒性沟道流动给出source-supported pos。2016近景和Elk的粗颗粒/木质夹带更清楚；2017狭长远景与HPCC雨滴画面的视觉把握较弱，表中明确来源证据承担更多作用。2017日期冲突不等于类别未知，两段仍共用一个日期未定的原来源事件。视频存在性pos仅表示至少出现过目标，**不表示所有帧/窗口为pos**，不据此报告起始时刻、定位或提前量。

**时钟分层：本最小8条真实采集时钟 verified=0、unknown=8；全22条 verified=0、unknown=22。** 现有完整解码/PTS可证明出版或容器时序，不能代替真实采集频率/速度认证。来源称相机记录或标称30fps也不在本轮升级为camera-clock verified。因而这些材料至多建议为“出版/容器时钟下的外部存在性挑战”，不能混称物理3秒实时测试。Silverado两块尤其不能根据130秒发布片推断约3分钟初始流至峰值的真实速度。

## 冻结前的有界处理事项

1. 对上述8条先按表中区间和同源关系完成一次独立标签/纳入审查，冻结视频级标签、媒体SHA、站点/事件/相机组及publication-clock身份。USU尚未做当前模型的3秒16个不同真实索引/QC映射，应做输入验收；不需要伪造逐帧语义真值。
2. Elk虽然拟pos，但主体仍有直接类别字幕，暂不纳入主计分子集，先决定与全体材料一致的类别文字处理规则。USGS标志、站点背景与类别来源相关，后续结果必须报告这种域差异，不能把外部成绩解释为已排除所有捷径。
3. 两条浑水仅需有界的约40秒运动复核或事件特定记录来区分流态；夜景需要足够可见性或事件记录。三条uncertain暂不计分，不反复补无限帧认证，也不根据模型分数改标签。
