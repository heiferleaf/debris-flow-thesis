## 问题与证据范围

在已有区间标注下，同场次正负片段的相对监督，能否改善弱可见正片段的判别，同时不增加整视频错误？保留RGB骨干和分类头，不增帧差或聚合模块。普通BCE本来就区分正负，新增排序可能冗余，必须用两个对照。

## 三组、模型与优化

- A：只计算BCE。
- B：BCE＋随机跨场次正负排序；在每配对microbatch内对相同负端点作固定跨场次置换。
- C：BCE＋同场次正负排序。

B/C使用完全相同的正负端点、对数、曝光次数、批次及顺序，只改变配对关系；A也使用同一批次顺序。三组重新从相同K400预训练状态和种子7初始化。旧EXP-016批次编排不同，不能直接替代本次A。

R(2+1)D-18六通道`[R,0]`、512→128→64→32→1头、三层Dropout0.5，全参数微调。Adam骨干1e-4／头1e-3，betas(0.9,0.999)、eps1e-8、weight_decay0；固定BN统计、训练仿射。FP32、无AMP／TF32、无增强，有效批次24、microbatch8。三组同初始化、同样本及Dropout随机流，20轮共420次更新，不扫描种子、lambda、跨度或学习率。

每microbatch对实际24窗有效批次反传：

`sum(weighted_BCE)/24 + lambda * (21/80) * sum(softplus(z_neg-z_pos))`

A的lambda为0，B/C均固定0.1。BCE的pos_weight=148/356。全轮排序项按80对归一，不按每个块重新取均值；每对等权，**不是场次等权**。无pair块的排序项为0。所有pair端点在同一microbatch，不能detach旧logit、额外前向或跨块保留网络图。非有限损失或梯度拒绝更新。

## 选轮、评价与晋级规则

每组完整训练20轮，按同136固定片段的最低未加权BCE选轮，相同取早；保留所有轮日志及预测。每组仅选中权重进行一次31条完整视频评价：复用标签无关3秒／1.5秒网格、相同质量／cut规则、max聚合、0.5阈值，完整32567窗，逐视频像素摘要须与已有本地参考一致。云端不提前为预检重复解码；训练读已验JPEG，正式评价才重算输入并前向。

主探索指标：上述三个混合视频各自4P×4N的错序率，平分计0.5，再取视频宏平均。它们来自已用于方法选择的开发数据，不是独立样本或检验集；不作显著性主张。

全部满足才允许在本目标剩余预算内提出一次配对复核，不自动开跑：

1. A固定片段AUC>0.5且概率极差≥0.05，作为最低非退化检查；即使通过也不等于强基线。
2. C的主错序率比A与B均至少低0.05绝对值。
3. C的136窗未加权BCE不高于A与B；同一选中预测JSON统一用FP64稳定公式重算，组间比较容差1e-8。该门槛不是CPU/GPU或历史日志对账容差。
4. C完整视频FP、FN均不高于A与B。

任一不满足，结束本候选，不换seed寻找成功；A退化则报告对照不足，不以C战胜退化A宣称有效。排序正确仍可能两类一起超过0.5，必须同时看视频错误。有限但差的结果照实保留，按预定顺序A/B/C完成，不凭早期成绩挑着训练。非有限值、输入／划分／来源不一致、完整覆盖失败、耗时或费用超限即停止并关机，不能报完整三组结论。
